## Экономика (кратко)

* 1 базовая монета = 2 золота (`ECON_GOLD_PER_COIN` в `native.c`). Тарифы: 1,000 монет — 2,000 G; 6,500 — 10,000; 14,000 — 20,000; 45,000 — 60,000; 80,000 — 100,000; 170,000 — 200,000. Пак воскрешения (свиток + 800 монет) — 2,000 G.
* Источник цифр: формула дропа золота из `GameCanvas_dropItem` (шанс 40%, сумма `(5L+20)·(80..120)/1000`). **Темп 300 убийств/час — прикидка, не замер.**

## Открытые вопросы и план

Проверка на консоли (ждёт пользователя):
1. Дэш: герой продолжает бежать после дэша и после перехода между картами.
2. L/R в меню: все 9 вкладок, переключение из содержимого страницы и из попапов.
3. FPS-оверлей и лог `[slow]` в бою; просадки при критах и скиллах после новых нативов. Нужен лог из `logs_nx/`.
4. Special Shop: покупка пака, отказ при нехватке золота, текст попапа возвращается.

Известные недоделки:
* Строка «My Coins» в магазине не показывает золото; цены без разделителей тысяч (`200000 G`).
* Сообщение «Not enough Gold.» — это подменённый текст безопасного попапа «You have purchased Coins.» (другие попапы падают из списка тарифов). Подмена идёт по тексту в памяти гостя, при смене текста в APK перестанет работать.
* `resume_walk`: при упоре в стену с удержанным стиком возможно мелкое дрожание анимации (перенажатие раз в 6 кадров). Не проверялось.
* L/R на крайних вкладках не зацикливаются (игра упирается в край).
* Наши замены текстов сопоставляются по точному совпадению; русской/корейской версии текстов (`gametxt.tdt`) они не касаются.

Идеи следующих этапов:
* **Локализация на русский язык**:
  * Анализ растрового шрифта `assets/dotum08.fnt` (`ZCP\0` + zlib) на предмет добавления кириллических глифов (или замена/расширение атласа символов).
  * Перевод текстов диалогов, квестов и интерфейса (`gametxt_en.tdt`, `gametxt_f_en.tdt`, таблицы `*_en.ddt`).
  * Механизм подгрузки: на лету через `host_asset_read()` (по аналогии с `economy_patch_asset`) либо чтение внешних файлов русификатора из каталога с игрой; опция/переключатель языка (CLI флаг `--lang ru` / настройка).
* Остаточные горячие места боя по профилю: `_drawMiniMap` ~17%, `Grp_drawClipWImageP` / `Grp_drawSimpleClipWImageP` (нативна только часть blit), `Map_drawBuff`, `Grp_drawExpandWImageP`, `Grp_setValidRect`. Порядок: профиль на боевом скрипте → нативная замена → `--hle 40` и сравнение md5 с `--hle -1`.

## Грабли

* Структуры гостя (смещения `GameUI`, `MenuCanvas`, `CASH_RATIO` и т. п.) найдены для этой сборки `libdestinia_jni.so`; на другой версии они неверны.
* Инструмент REA (`procedure_pseudo_code`) на этой машине зависает; надёжнее `arm-none-eabi-objdump -d -M force-thumb` по `work/apk/lib/armeabi/libdestinia_jni.so`.
* Режим `--hle 40` очень медленный (~30 мин на 4800 кадров); для быстрой проверки сравнивайте манифесты `--manifest` с `--hle -1` (~2 мин).
* Python-инструменты запускать через `/usr/bin/python3`, не через mise.
