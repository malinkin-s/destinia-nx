## Архитектура проекта

```text
destinia-nx/
├── port/
│   ├── src/
│   │   ├── cpu.c          # Легковесный интерпретатор ARMv5 Thumb
│   │   ├── hle.c          # Высокоуровневая эмуляция JNI, Android OS и libc
│   │   ├── native.c       # Нативные C-блиттеры, оверлеи UI, экономика и патчи
│   │   ├── apk.c          # Чтение ассетов напрямую из zip-архива APK
│   │   ├── audio.c        # Вывод звука и BGM через SDL2_mixer (Switch)
│   │   └── main.c         # Цикл игры, обработка геймпада, хотбар, VSync
│   ├── tests/
│   │   └── golden.sh      # 700-кадровый регрессионный тест (бит-в-бит)
│   ├── Makefile           # Сборка под Linux PC
│   └── Makefile.switch    # Сборка под Nintendo Switch (libnx + SDL2)
├── tools/
│   ├── build_switch.sh    # Компиляция NRO через Docker devkitA64
│   ├── build_forwarder.sh # Сборка Forwarder NSP/NSZ (hacBrewPack + nsz)
│   └── package.sh         # Упаковка релизного архива zip
├── dist/                  # Релизные бинарники (NRO, NSP, NSZ, ZIP)
├── docs/                  # Документация (HANDOFF, economy, медиа)
├── work/                  # Исходники APK и декомпиляция для локализации
└── ref/                   # Референсный код (android32)
```

## Экономика (кратко)

* 1 базовая монета = 2 золота (`ECON_GOLD_PER_COIN` в `native.c`).
* Тарифы:
  - 1,000 монет — 2,000 G
  - 6,500 монет — 10,000 G
  - 14,000 монет — 20,000 G
  - 45,000 монет — 60,000 G
  - 80,000 монет — 100,000 G
  - 170,000 монет — 200,000 G
* Пак воскрешения на экране смерти: 2,000 G (или экстренное воскрешение за `min(gold, 200)` при нехватке золота).
* Подробные расчёты: [docs/economy.md](economy.md).

## План на следующий этап: Русская локализация

1. **Шрифты (`assets/dotum08.fnt`)**:
   - Формат шрифта: заголовок `ZCP\0` + сжатые zlib данные символов и метрик.

2. **Текстовые ресурсы**:
   - `assets/gametxt_en.tdt` и `assets/gametxt_f_en.tdt` — тексты диалогов, квестов и сюжетных сцен.
   - `assets/*_en.ddt` — названия предметов, умений, экипировки и описания характеристик.
   - Декомпилированные Java-классы в `work/jadx_out/` содержат структуры парсеров этих файлов.
3. **Механизм подгрузки перевода**:
   - Реализовать загрузку через `host_asset_read()` в `port/src/main.c` (по аналогии с `economy_patch_asset`) либо чтение внешних файлов из каталога `sdmc:/switch/destinia/lang/ru/`.
   - Добавить флаг или автоопределение языка консоли через `setGetSystemLanguage()` в libnx.
